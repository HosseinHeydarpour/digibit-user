# دیجی‌بیت مارکت — وب‌سایت کاربر

صفحه فرود (Landing) پروژه. در حال حاضر فقط صفحه **«به‌زودی»** در این مخزن قرار دارد.

> ⚠️ فایل‌های سایت **در ریشه مخزن** قرار دارند (نه در پوشه‌ای جدا).
> این کار عمدی است تا **GitHub Pages** بتواند سایت را بسازد، چون Pages فقط از
> ریشه مخزن یا پوشه `/docs` منتشر می‌کند.

## ساختار

```
<ریشه مخزن>/
├── index.html                  ← صفحه «به‌زودی» (تنها صفحه فعلی)
├── .nojekyll                   ← جلوگیری از پردازش Jekyll توسط GitHub Pages
├── README.md
└── assets/
    ├── css/style.css           ← تمام استایل صفحه + متغیرهای رنگی (بخش :root)
    ├── js/coming-soon.js       ← تایمر شمارش معکوس + فرم ثبت ایمیل
    ├── font/
    │   ├── yekan-bakh/         ← فونت یکان‌بخ (۶ وزن، woff2)
    │   └── bootstrap-icon/     ← آیکون‌های Bootstrap Icons
    └── img/
        ├── logo.png            ← لوگو (نشان «دیجی‌بیت») — هدر صفحه
        ├── logo-full.png       ← لوگوی کامل (نشان + DIGIBIT + خط)
        ├── favicon-32.png      ← فاوآیکون ۳۲×۳۲
        ├── favicon-16.png      ← فاوآیکون ۱۶×۱۶
        └── apple-touch-icon.png← آیکون iOS (۱۸۰×۱۸۰)
```

> پوشه `website-temp/` فقط مرجع طراحی است (قالب «شاهان») و در گیت ثبت نمی‌شود؛
> در `.gitignore` قرار دارد. صفحه «به‌زودی» کاملاً مستقل است و به آن پوشه نیازی ندارد.

## انتشار روی GitHub Pages

- **Source:** `Deploy from a branch` → Branch: **`main`** → Folder: **`/(root)`**
- **آدرس سایت:** <https://hosseinheydarpour.github.io/digibit-user/>
- در حال حاضر **دامنه اختصاصی تنظیم نشده** (فایل `CNAME` وجود ندارد).

> وضعیت دامنه `digibitshop.ir` (بررسی‌شده): در ایرنیک **ثبت شده** و نیم‌سرورهای آن
> `cloud.parspack.net` و `cape.parspack.net` هستند، ولی زون دامنه روی پارس‌پک ساخته
> نشده — پرسیدن رکورد A از همان نیم‌سرورها پاسخ «DNS operation refused» می‌دهد و
> دامنه در DNS resolve نمی‌شود. تا این مورد حل نشود، دامنه را به عنوان Custom domain
> در Pages ثبت نکنید.

> ⚠️ اگر فایل `CNAME` اضافه شود ولی دامنه در ایرنیک ثبت نشده و DNS آن ست نشده باشد،
> سایت از **هیچ آدرسی** باز نمی‌شود — چون GitHub Pages آدرس `*.github.io` را هم به
> دامنه اختصاصی ریدایرکت می‌کند و آن دامنه resolve نمی‌شود.

برای وصل کردن دامنه، ترتیب کار این است:

1. اول دامنه را ثبت کنید و DNS آن را ست کنید:

   | نوع | نام هاست | مقدار |
   |---|---|---|
   | `A` | `@` | `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` |
   | `CNAME` | `www` | `hosseinheydarpour.github.io` |

2. **بعد** در Settings → Pages دامنه را در «Custom domain» وارد کنید تا فایل `CNAME` ساخته شود.
3. پس از صدور گواهی، **Enforce HTTPS** را فعال کنید.

## اجرا

فایل `index.html` را در مرورگر باز کنید؛ همه مسیرها نسبی‌اند و به سرور نیازی نیست.
(برای تست دقیق‌تر که مسیرها از ریشه سرو شوند، یک سرور محلی هم می‌توانید اجرا کنید.)

## تنظیم تاریخ افتتاح

تاریخ در یک خط مشخص می‌شود — در `index.html`:

```html
<script>
    window.DIGIBIT = {
        target: '2027-01-01T00:00:00Z',   // ← این خط را ویرایش کنید
        preview: /(?:\?|&)mode=preview(?:&|$)/.test(location.search)
    };
</script>
```

- تاریخ به‌صورت **UTC / ISO 8601** نوشته می‌شود.
- بدون ویرایش کد هم می‌توان تاریخ را تست کرد: `index.html?target=2027-06-01T00:00:00Z`
- پیش‌نمایش سریع: `index.html?mode=preview` → شمارش معکوس ۳۰ ثانیه‌ای،
  برای دیدن هم حالت تایمر و هم حالت «افتتاح‌شده» بدون انتظار.

## رفتار صفحه

- **شمارش معکوس** با اعداد فارسی (روز / ساعت / دقیقه / ثانیه) و به‌روزرسانی هر ثانیه.
- پس از رسیدن به صفر، تایمر و فرم پنهان و دکمه **«ورود به فروشگاه»** نمایش داده می‌شود.
- **فرم ثبت ایمیل** اعتبارسنجی سمت کلاینت دارد و آدرس‌ها را در `localStorage`
  (کلید `digibit-coming-soon-subscribers`) ذخیره می‌کند.
  ⚠️ برای دریافت واقعی ایمیل‌ها باید به سرویس بک‌اند وصل شود.
- شمارش معکوس سمت مرورگر محاسبه می‌شود، پس کش شدن HTML توسط CDN آن را خراب نمی‌کند.

## نکات

  نشانی صفحه اصلی فروشگاه را جایگزین کنید.
- شماره تماس و ایمیل واقعی در پنل تماس ثبت شده‌اند:
