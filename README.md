- **Source:** `Deploy from a branch` → Branch: **`main`** → Folder: **`/(root)`**
- **آدرس سایت:** <https://digibitshop.ir/> (دامنه اختصاصی، فعال و دارای SSL)
- آدرس `hosseinheydarpour.github.io/digibit-user/` به دامنه بالا ریدایرکت می‌شود.
- فایل `CNAME` در ریشه مخزن مقدار `digibitshop.ir` را نگه می‌دارد.

رکوردهای DNS فعلی دامنه:

| نوع | نام هاست | مقدار |
|---|---|---|
| `A` | `@` | `185.199.108.153` |
| `A` | `www` | هر چهار آی‌پی `185.199.108` تا `185.199.111.153` |

> ⚠️ بهتر است برای `@` هم **هر چهار آی‌پی** ثبت شود (نه فقط یکی) تا اگر یکی از
> سرورهای گیت‌هاب از دسترس خارج شد، سایت پایدار بماند.

> ⚠️ اگر دامنه را از Settings → Pages بردارید یا `CNAME` را حذف کنید، حتماً توجه کنید
> که GitHub Pages آدرس `*.github.io` را به دامنه اختصاصی ریدایرکت می‌کند؛ اگر دامنه
> resolve نشود، سایت از **هیچ آدرسی** باز نمی‌شود.

## اجرا

فایل `index.html` را در مرورگر باز کنید؛ همه مسیرها نسبی‌اند و به سرور نیازی نیست.
(برای تست دقیق‌تر که مسیرها از ریشه سرو شوند، یک سرور محلی هم می‌توانید اجرا کنید.)

## تنظیم تاریخ افتتاح

تاریخ در یک خط مشخص می‌شود — در `index.html`:

```html
<script>
    window.DIGIBIT = {
        target: '2027-01-01T00:00:00Z',   // ← این خط را ویرایش کنید
        preview: /(?:\?|&)mode=preview(?:&|$)/.test(location.search)
    };
</script>
```

- تاریخ به‌صورت **UTC / ISO 8601** نوشته می‌شود.
- بدون ویرایش کد هم می‌توان تاریخ را تست کرد: `index.html?target=2027-06-01T00:00:00Z`
- پیش‌نمایش سریع: `index.html?mode=preview` → شمارش معکوس ۳۰ ثانیه‌ای،
  برای دیدن هم حالت تایمر و هم حالت «افتتاح‌شده» بدون انتظار.
